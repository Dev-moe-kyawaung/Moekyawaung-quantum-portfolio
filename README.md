# ⚛ Quantum Matrix Portfolio

A cutting-edge, quantum-themed portfolio website for **Moe Kyaw Aung** — Senior Android Developer.

## 🌟 Features

- **Quantum Animated Background**: Matrix rain effect with cascading data and particle system
- **Floating AI Orb**: Interactive quantum orb that responds to user interactions
- **Project Network Visualization**: Projects displayed as quantum nodes with connection lines
- **Dark/Light Theme**: Seamless theme switching with persistence
- **Custom Cursor**: Interactive cursor with glow effects
- **Typing Animation**: Dynamic hero text with blinking cursor
- **Particle.js Integration**: Interactive particle background
- **Mobile Responsive**: Optimized for all devices
- **Performance Optimized**: Lazy loading and smooth animations
- **SEO Ready**: Meta tags and semantic HTML

## 📁 Project Structure

```
quantum-portfolio/
│
├── index.html          # Main HTML file
├── css/

├── js/
│   ├── data.js         # Data configuration
│   ├── quantum.js      # Quantum effects
│   ├── particles.js    # Particle system
│   └── main.js         # Main application logic
└── assets/             # Images and other assets
```

## 🚀 Quick Start

1. Clone the repository:
```bash
git clone https://github.com/Dev-moe-kyawaung/quantum-portfolio.git
```

2. Open `index.html` in your browser

Or deploy to GitHub Pages/Netlify/Vercel.

## 💻 Technologies

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Framework**: Vanilla JS (No dependencies!)
- **Effects**: Canvas animations, Particle systems
- **Fonts**: Inter, JetBrains Mono
- **Icons**: Font Awesome 6

## ⚙️ Customization

### Colors
Edit CSS variables in `style.css`:
```css
:root {
    --accent-cyan: #00f0ff;
    --accent-purple: #a855f7;
    --bg-primary: #0a0e17;
}
```

### Content
Update `data.js` with your:
- Projects
- Certifications
- GitHub accounts
- Blog posts
- Testimonials
